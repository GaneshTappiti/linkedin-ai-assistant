# LinkedIn Content Generation Prompts

## Behind-the-Scenes Post Template
```
/linkedin-content

Topic: [Your topic/lesson]
Experience: [What you went through]
Duration: [How long it took / how many years experience]
Key Lesson: [What you learned]
Audience: [Who should care?]

Generate a behind-the-scenes post about my experience with [topic]. 
Use "I/I've/when" language to make it personal.
Target audience: [founders/engineers/marketers]
Include: [specific insight or framework]
Make it share-worthy and relatable.
```

## Value-Packed Post Template
```
/linkedin-content

Framework: [Your system/framework name]
Elements: [List the 3-5 key elements]
Format: Personal story → System breakdown → Actionable takeaway

Create a value-packed post that:
1. Opens with a personal challenge or story
2. Introduces my [framework/system]
3. Breaks down each element with examples
4. Ends with actionable next steps
5. Image description: handwritten visual showing the framework
Include relevant statistics or data points.
```

## System Deep-Dive Template
```
/linkedin-content

System: [Name of your system]
How long you've used it: [Duration]
Results: [Measurable outcomes]
Audience: [Target personas]
What problems it solves: [List 3-5]

Write a detailed system breakdown post showing:
- How the system works step-by-step
- Specific examples from my experience
- Measurable results I've achieved
- How readers can implement it
Include: Real numbers, case studies, before/after
Make it: Deep, detailed, and immediately actionable
```

## Personal Story Template
```
/linkedin-content

Story: [Brief title of the story]
Timeline: [When this happened, how long]
Challenge: [The problem I faced]
Transformation: [What changed]
Lesson: [What I learned]
Audience: [Who needs this lesson]

Write a personal vulnerability-focused post:
- Start with the challenge/vulnerability
- Share the struggle and mistakes
- Reveal the turning point
- Show the lesson learned
- Connect to professional growth
- End with a question for engagement
Make it authentic, relatable, and inspirational.
```

## Data-Driven Post Template
```
/linkedin-content

Data Point: [The statistic/research]
Source: [Where it's from]
Implication: [Why it matters]
Context: [What you're building/working on]
Audience: [Who cares about this]

Create a data-driven LinkedIn post:
1. Open with a surprising statistic
2. Provide context about the data
3. Share my perspective/experience with it
4. Explain why it matters for [audience]
5. Suggest one action based on the insight
Include: Source, additional data points, real-world application
Make it: Thought-provoking and shareable
```

## Weekly Content Series Template
```
/linkedin-content

Theme: [Weekly theme - e.g., "AI Systems Week"]
Days: [Mon-Fri content plan]
Topics:
- Monday: [Topic 1]
- Tuesday: [Topic 2]
- Wednesday: [Topic 3]
- Thursday: [Topic 4]
- Friday: [Topic 5]

Create a 5-post week plan where:
1. Each post uses a different format
2. They build upon each other thematically
3. Include mix of behind-scenes, systems, stories, value-bombs
4. Each has custom hooks, CTAs, and hashtags
5. Engagement strategy for the week
Format as: Ready-to-post content with scheduling suggestions
```

## Hook Variations Template
```
/linkedin-content

Main Topic: [Your topic]
Key Insight: [The main point]
Post Goal: [Followers / Engagement / Leads]

Generate 5 alternative hooks for this topic:
1. Curiosity hook (opens question)
2. Contrarian hook (challenges common wisdom)
3. Data hook (statistics-driven)
4. Personal hook (vulnerability-focused)
5. Identity hook (calls out specific people)

For each hook:
- Create first 3 lines (scroll-stopper)
- Explain why it works
- Suggest best for: [Audience type]
```

## Case Study Post Template
```
/linkedin-content

Case: [Project / Implementation / Result]
Timeline: [Duration]
Problem: [What was the challenge]
Solution: [What did you do]
Results: [Measurable outcomes]
Key Insight: [The learning]

Write a case study post:
1. Hook with the result (e.g., "Grew 846K followers in 36 months")
2. Explain the initial challenge
3. Walk through your system/approach
4. Share specific tactics and metrics
5. Discuss what worked vs didn't
6. End with actionable takeaways
Include: Numbers, frameworks, timeline
Make it: Detailed, credible, immediately applicable
```

## Engagement Optimization Template
```
/linkedin-content

Topic: [Your topic]
Draft Post: [Paste your post]

Analyze this post for:
1. Hook quality (does it stop the scroll?)
2. Value per line (high-value content density?)
3. Actionable takeaways (clear next steps?)
4. Share-worthiness (would people repost this?)
5. CTA effectiveness (clear ask?)

Suggestions for:
1. Stronger hook
2. Better pacing
3. Improved CTAs
4. Hashtag recommendations
5. Optimal posting time
6. Follow-up engagement strategy
```

## A/B Testing Template
```
/linkedin-content

Post Concept: [Main idea]
Primary Audience: [Who you're targeting]
Goal: [Followers / Engagement / Leads / Visibility]

Create 3 versions of this post optimized for A/B testing:

Version A: Curiosity-focused
- Hook emphasizing mystery/intrigue
- Best for: Re-engages cold followers

Version B: Data-focused  
- Hook emphasizing statistics
- Best for: Attracts analytical audience

Version C: Story-focused
- Hook emphasizing personal narrative
- Best for: Builds meaningful connections

Testing plan: Which to post first, when to measure, success metrics
```
