# Normalized Memory Bundle

This folder contains the canonical, deduplicated memory package used by agents.

## Files
- `linkedin_master_export_deduped.json`: Final deduplicated profile export
- `goals_vision_building_focus.json`: Structured synthesis of identity, goals, and active builds
- `profile_comprehensive_analysis.json`: Metrics + summary analysis
- `normalization_summary_report.json`: Consolidated normalization report
- `PERSONAL_SYNTHESIS_GANESH.md`: Human-readable comprehensive synthesis

## Usage Rule
Agents should load these files first on every task before generating plans or outputs.
